# Wiskunde Wilds

Educatieve wiskunde-avonturenwebapp voor de overstap van VWO 2 naar VWO 3.

**Train je skills. Ontdek patronen. Level up naar VWO 3.**

## Starten

```bash
npm install
npm run dev
```

Open daarna de URL die Vite toont (meestal `http://localhost:5173`).

## Scripts

- `npm run dev` — lokale ontwikkelserver
- `npm run build` — productiebuild
- `npm run preview` — preview van de build

## Kenmerken

- 8 bosgebieden / lessen met echte challenges
- Sterren, XP, streaks en badges
- Voortgang in `localStorage` (geen backend)
- Skills-overzicht, instellingen, responsive layout

Alles draait lokaal. Geen accounts, geen API-keys.
